Sales Performance Dashboard using Microsoft Excel. This project analyzes sales, profit, product categories, state-wise sales, and monthly performance using Pivot Tables, Charts, and Slicers to visualize business insights and support data-driven decision-making.

# Sales Performance Dashboard – Microsoft Excel

## Project Overview

The Sales Performance Dashboard is an interactive data analysis project developed using Microsoft Excel. The project analyzes sales data to identify business trends, evaluate profitability, and understand sales performance across different product categories, states, and months.

The dashboard uses PivotTables, charts, and interactive visualizations to transform raw sales data into meaningful business insights.

## Project Objectives

- Analyze overall sales and profit performance.
- Identify the highest-selling product category.
- Find the state with the highest sales.
- Identify the most profitable product category.
- Analyze monthly profit performance.
- Understand sales trends across different years.

## Tools & Technologies

- Microsoft Excel
- PivotTables
- PivotCharts
- Interactive Slicers
- Data Analysis
- Data Visualization

##  Key Business Questions

1. What are the total sales and total profit?
2. Which product category generates the highest sales?
3. Which state has the highest sales?
4. Which product category generates the highest profit?
5. Which month performs best in terms of profit?

##  Key Insights

- Total Sales: $2,297,201.07
- Total Profit: $286,397.79
- Technology is the highest-selling category.
- California has the highest state-wise sales.
- Technology generates the highest profit.
- December is the highest-profit month.

## Dashboard Features

- Sales and profit analysis.
- Category-wise sales comparison.
- State-wise sales performance.
- Category-wise profit analysis.
- Monthly profit analysis.
- Interactive data filtering using slicers.

## How to Use

1. Download the Excel project file from this repository.
2. Open the file using Microsoft Excel.
